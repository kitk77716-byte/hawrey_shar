هاوڕێی شار (HAWREY) — ڕێنمایی بەکارهێنان
========================================

گرنگ: ئەم وەشانە هیچ Database ـێک و هیچ Login ـێکی گشتی نییە.

پێکهاتەی فایلەکان:
- public/                 : سەرچاوەی ماڵپەڕی گشتی و داتای شوێنەکان.
- github-pages/           : فایلە ئامادەکان بۆ بارکردن لە ڕەگی GitHub repository.
- private-admin/admin.html: پەڕەی تایبەتی خاوەن ماڵپەڕ بۆ زیادکردن و دەستکاریکردن.
- داتای دەستپێک: ٣٩ شوێنی گەشتیاری، چێشتخانە و کافێ لە سلێمانی و چەند شاری دیکە.

چۆن خزمەتگوزاری زیاد بکەیت؟
1) private-admin/admin.html لە کۆمپیوتەرەکەت بکەرەوە؛ داتای سەرەتایی بە خۆکار لە public/data.js بار دەبێت.
2) ناو، جۆری خزمەتگوزاری، شار، تەلەفۆن و ناونیشان بنووسە.
3) لەسەر نەخشە کلیک بکە بۆ دیاریکردنی شوێنی ورد.
4) دوگمەی «زیادکردنی خزمەتگوزاری» دابگرە.
5) دوگمەی «داگرتنی data.js بۆ ماڵپەڕ» دابگرە.
6) فایلە data.js ـی نوێ لە github-pages دابنێ و جێگای فایلە کۆنەکەی بگرێتەوە.
7) لە GitHub repository ـەکەت، ناوەڕۆکی فۆڵدەری github-pages بار بکە بۆ ڕەگی repository (نەک خودی فۆڵدەری github-pages). فایلە نوێیەکان جێگای index.html، data.js، manifest.webmanifest، sw.js و فۆڵدەری icons دەگرنەوە.

چۆن ماڵپەڕەکە ببینی؟
- index.html لەگەڵ data.js لە هەمان فۆڵدەر دابنێ.
- بۆ تاقیکردنەوە باشترە VS Code و Live Server بەکاربهێنیت، یان فایلەکان لە هۆستینگێکی Static Web بڵاو بکەیتەوە.
- نەخشە پێویستی بە ئینتەرنێت هەیە (Leaflet + OpenStreetMap؛ ئەگەر خزمەتگوزاریی سەرەکی نەبوو CARTO وەک جێگرەوە تاقی دەکرێتەوە + Esri World Imagery). ئەم وەشانە ئەگەر CDN یەکەم کار نەکات CDN ی دووەم تاقی دەکاتەوە و هۆکاری نەباربوونی نەخشە لەسەر شاشە پیشان دەدات.

تایبەتمەندییە نوێکانی نەخشە:
- گۆڕینی جۆری نەخشە لە نێوان شەقام و وێنەی ئاسمانی.
- زووم، پێوانەی مەودا و گەورەکردنی نەخشە.
- نیشاندانی شوێنی ئێستا بە مۆڵەتی وێبگەڕ.
- گەڕان بە ناوی شوێن/ناونیشان لەسەر نەخشە؛ گەڕان بە دەستییە و autocomplete نییە.
- لە پاپ-ئاپی هەر خزمەتگوزارییەکدا لینک بۆ بینین لە Google Maps و وەرگرتنی ڕێنیشاندەر.
- لە پەڕەی ئەدمینیش دەتوانیت شوێن بگەڕێیت و پاشان پینەکە ڕاست بکەیتەوە.

تێبینی: نەخشەکە خۆی Google Maps نییە؛ لە OpenStreetMap و وێنەی ئاسمانی Esri بەکاردەهێنێت. لینکەکان Google Maps لە دەرەوە دەکەنەوە. بۆ دانانی خودی Google Maps و خزمەتگوزاری Google Places لە ناو وێب‌سایت، کلیلی API و ڕێکخستنی هەژماری Google پێویستە. هەموو شوێنەکانی Google Maps بە شێوەی ئۆتۆماتیکی لەم وەشانەدا هەناردە ناکرێن.

بۆ بەکارهێنانی شوێنی ئێستا، ماڵپەڕەکە دەبێت لە HTTPS یان localhost بکرێتەوە؛ لە file:// ڕەنگە مۆڵەتی شوێن کار نەکات.

گەڕانی ناونیشان بە خزمەتگوزاری گشتی Nominatim ـی OpenStreetMap کار دەکات؛ ئەم خزمەتگوزارییە سنووری بەکارهێنان هەیە، بۆیە گەڕان بە دەستی و بێ autocomplete دانراوە. بۆ بەکارهێنانی بازرگانی و زۆر، پێویستە geocoding provider ـێکی تایبەت یان سێرڤەری خۆت هەڵبژێریت.

چۆن داتای پێشوو بگەڕێنیتەوە؟
- لە admin.html دوگمەی «بارکردنی data.js ـی پێشوو» دابگرە و فایلە data.js ـی ناو public هەڵبژێرە.

پاراستن و سنوورەکان:
- تەنها فۆڵدەری public بخەرە سەر هۆستینگ. فۆڵدەری private-admin لە کۆمپیوتەرەکەت بهێڵەوە و بڵاوی مەکەرەوە.
- ماڵپەڕی گشتی Login نییە؛ هەموو کەس دەتوانێت زانیارییە بڵاوکراوەکان ببینێت، بەڵام ناتوانێت لە ڕووکاری گشتی زیادکاری بکات.
- خاوەن فایلەکان تەنها کەسێکە کە دەتوانێت داتاکان بگۆڕێت و data.js نوێ بکاتەوە.
- داتاکان لە localStorage ـی براوزەرەکەتیش هەڵدەگیرێن؛ بەڵام فایلە data.js داگرتنەکە بکە بۆ Backup و بڵاوکردنەوە.
- بۆ ئەوەی گۆڕانکارییەکان بۆ هەموو خەڵک دیاربن، پێویستە data.js ـی نوێ لە هۆستینگ جێگای فایلە کۆنەکە بگرێتەوە.

ماپ و خزمەتگوزارییەکان:
- کاتێک خزمەتگوزارییەکی نوێ زیاد دەکەیت، دڵنیابە لە Latitude و Longitude ـی دروست.
- بۆ دڵنیایی لە زانیارییەکانی پیشەکار، پێش بڵاوکردنەوەی ژمارە و ناونیشان ڕەزامەندی خاوەن خزمەتگوزاری وەربگرە.


چارەسەری کێشەی نەخشە:
- پەڕەکە لە Chrome یان Firefox و بە ئینتەرنێت بکەرەوە.
- باشترە لە VS Code بە Live Server یان لە هۆستینگی HTTPS بیکەیتەوە؛ پێویست ناکات لە Google Maps API Key بەکاربهێنیت بۆ ئەم نەخشەیە.
- ئەگەر پەیامی «کتێبخانەی نەخشە بار نەبوو» دەرکەوت، دەستگەیشتن بە CDN داخراوە. ئەگەر نەخشە خاڵە سپییەکانی تێدا بوو یان سەوز/خاکستەری مایەوە، دەستگەیشتن بە سێرڤەری tile داخراوە یان ئینتەرنێت لاوازە.
- دوگمەی شوێنی من تەنها لە localhost یان HTTPS و بە ڕەزامەندی وێبگەڕ کار دەکات.


بەکارهێنان لە مۆبایل، تابلێت و ئایفۆن:
- وەشانی نوێ Responsive ـە و بۆ شاشەی مۆبایل، تابلێت و کۆمپیوتەر ڕێکخراوە.
- بۆ دامەزراندنی وەک ئەپ، ماڵپەڕەکە لە هۆستینگێکی HTTPS بڵاو بکەرەوە.
- لە Android/Chrome: مێنیو بکەرەوە و Install app یان Add to Home screen هەڵبژێرە.
- لە iPhone/iPad/Safari: دوگمەی Share بکە، پاشان Add to Home Screen هەڵبژێرە.
- بۆ دەستکاریکردنی بەشی ئەدمین لە مۆبایل، فایلی private-admin/admin.html لە Safari/Chrome بکەرەوە. بۆ بەکارهێنانی شوێنی ئێستا و ڕێکخستنی PWA، HTTPS پێویستە.
- PWA ناوەڕۆکی سەرەکی دەپارێزێت بۆ کاتی بێ‌ئینتەرنێت؛ بەڵام نەخشە و گەڕانی شوێن و وێنەی ئاسمانی پێویستیان بە ئینتەرنێت هەیە.
- بۆ نوێکردنەوەی ماڵپەڕ، فایلە نوێیەکانی public لە هۆستینگ جێگای فایلە کۆنەکان بگرنەوە.


دەربارەی داتای دەستپێک:
- ئەم پەکێجە ٣٩ تۆماری دەستپێکی هەیە: شوێنە مێژوویی و سروشتییەکان و هەندێک چێشتخانە/کافێ. ئەمە لیستی هەموو شوێنەکانی کوردستان نییە.
- خاڵەکانی نەخشە لە سەرچاوە گشتییەکان و پێوانەی ناونیشانەکان وەرگیراون؛ لە کاتی زیادکردنی نوێ یان بڵاوکردنەوە، پینەکان لەسەر نەخشە بپشکنە و ئەگەر پێویست بوو ڕاستیان بکەرەوە.
- کاتژمێری کارکردن، نرخ و خزمەتگوزارییە وردەکان لەم داتایەدا دانەنراون؛ پێش بڵاوکردنەوەی ژمارە و ناونیشانەکان لەگەڵ خاوەنی شوێنەکە پشتڕاستیان بکەرەوە.
- بۆ شوێنە گەشتیارییە پیرۆز و ئایینییەکان، ڕێنمایی و ڕێوڕەسمی ناوخۆیی ڕەچاو بکە.
