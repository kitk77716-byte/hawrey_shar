بەڕێوەبردنی هاوڕێی شار

تەنها بۆ خاوەنی ماڵپەڕ · زیادکردن و دەستکاریکردنی خزمەتگوزاری لەسەر نەخشە

تێبینی تایبەت: ئەم پەڕەیە تەنها بۆ خۆتە و لە ماڵپەڕی گشتی بڵاوی مەکەرەوە. لێرە هیچ Login و Database ـێک نییە. داتاکان لە براوزەری خۆت پاشەکەوت دەبن؛ بۆ نوێکردنەوەی وێب‌سایت، دوای گۆڕانکاری «داگرتنی data.js» بکە و فایلە نوێیەکە لەگەڵ index.html دابنێ.

زیادکردنی خزمەتگوزاریی نوێ

لەسەر نەخشە کلیک بکە بۆ دیاریکردنی شوێن. یان ژمارەی Latitude و Longitude بنووسە.

شوێن دیاری بکە

نەخشە بار دەکرێت...

لە هەر شوێنێکی نەخشە کلیک بکە؛ پینەکە دەگوازرێتەوە و شوێنەکە لە فۆڕمەکەدا تۆمار دەبێت. دەتوانیت گەڕان، وێنەی ئاسمانی و شوێنی ئێستاش بەکاربهێنیت. بۆ شارێکی تر، لە لیستی شارەکان هەڵیبژێرە و پاشان لە نەخشە شوێنەکە دیاری بکە.

خزمەتگوزارییە تۆمارکراوەکان

دوای زیادکردن یان دەستکاریکردن، فایلە data.js ـەکە دابگرە. لە فۆڵدەری وێب‌سایتەکەتدا فایلە کۆنەکەی پێ بگۆڕە، پاشان فایلە نوێیەکان بڵاو بکەرەوە.

ئەم وەشانە Database بەکارناهێنێت. تەنها data.js داتاکان هەڵدەگرێت. ئەگەر ماڵپەڕەکە بۆ هەمووان بڵاو بکەیتەوە، هەر کەس دەتوانێت زانیارییەکان ببینێت، بەڵام تەنها ئەو کەسەی فایلەکانی خاوەندارێتی دەکات دەتوانێت داتاکان بگۆڕێت. بۆ پاراستنی زیاتر، admin.html مەخەرە سەر هۆستینگی گشتی.
