هاوڕێی شار — ڕێنمایی خێرای بەشی ئەدمین
==========================================

ئامانج:
تۆ لەسەر کۆمپیوتەرەکەت پەڕەی تایبەتی ئەدمین دەکەیتەوە، شوێن لەسەر نەخشە دیاری دەکەیت، خزمەتگوزاری زیاد/دەستکاری/سڕینەوە دەکەیت، پاشان data.js نوێ دەکەیتەوە بۆ ئەوەی لە وێبسایتی گشتی دیار بێت.

١) فایلی data.js ـی ئێستای سایتەکەت دابگرە
- ئەم لینکە بکەرەوە:
  https://raw.githubusercontent.com/kitk77716-byte/hawrey_shar/main/data.js
- کلیکی ڕاست لە پەڕەکە بکە و Save as هەڵبژێرە، یان Ctrl+S دابگرە.
- ناوی فایلەکە دەبێت data.js بێت.

٢) پەڕەی ئەدمین بکەرەوە
- ZIP ـەکە Extract All بکە.
- بچۆ ناو فۆڵدەری hawrey_shar، پاشان private-admin.
- فایلی admin.html بە Chrome بکەرەوە.
- بۆ کارکردنی نەخشە پێویستە ئینتەرنێتت هەبێت.

٣) داتاکانی پێشوو بار بکە
- لە بەشی «خزمەتگوزارییە تۆمارکراوەکان» دوگمەی «بارکردنی data.js ـی پێشوو» دابگرە.
- ئەو data.js ـە هەڵبژێرە کە لە هەنگاوی ١ داتداگرت.
- ئەمە داتاکانی ئێستای سایتەکەت دەهێنێتە ناو ئەدمین، بۆیە داتای کۆن لەدەست نادەیت.

٤) شوێنێکی نوێ زیاد بکە
- ناوی خزمەتگوزاری/پیشەکار، جۆر، شار و زانیارییە پێویستەکان بنووسە.
- لە خانەی گەڕانی نەخشە ناوی شوێن یان ناونیشان بنووسە و «گەڕان» دابگرە.
- دەتوانیت بە دەستی لەسەر نەخشەش کلیک بکەیت؛ پینەکە دەتوانیت بجوڵێنیت.
- Latitude و Longitude خۆکارانە پڕ دەبن.
- دوگمەی «زیادکردنی خزمەتگوزاری» دابگرە.
- بۆ گۆڕینی یەکێک لە خزمەتگوزارییەکان «دەستکاری» و بۆ لابردنی «سڕینەوە» بەکاربهێنە.

٥) گۆڕانکارییەکان بڵاو بکەرەوە
- دوگمەی «داگرتنی data.js بۆ ماڵپەڕ» دابگرە.
- لە GitHub ـدا بچۆ ناو repository ـی hawrey_shar.
- فایلە data.js ـی سەرەکی لە ڕەگی repository ـەکەدا نوێ بکەرەوە بە فایلە تازەداگرتووەکە.
- تەنها data.js پێویستە بۆ زیادکردنی شوێنەکان نوێ بکرێتەوە؛ پێویست ناکات هەموو فایلەکان دووبارە بار بکەیت.
- دوای Commit changes، ماڵپەڕەکە نوێ بکەرەوە. بڵاوکردنەوەی GitHub Pages ڕەنگە چەند خولەک بخایەنێت.

لینکی ماڵپەڕ:
https://kitk77716-byte.github.io/hawrey_shar/

گرنگ — شوێنی پاراستنی فایلەکان:
- فۆڵدەری public پێکهاتەی ماڵپەڕە گشتییەکەیە. لە repository ـی ئێستات فایلەکانی ئەم فۆڵدەرە لە ڕەگی repository دانراون؛ کاتێک فایلەکانی public دەگوازیتەوە، ناوەڕۆکی فۆڵدەرەکە دابنێ، نەک خودی فۆڵدەری public.
- فۆڵدەری private-admin تەنها لە کۆمپیوتەرەکەت بهێڵەوە و بۆ GitHub Pages بڵاوی مەکەرەوە.
- ئەم سیستەمە Database و Login نییە. داتاکان لە براوزەری ئەدمین و لە فایلە data.js ـەکە هەڵدەگیرێن؛ گۆڕانکارییەکان بۆ هەمووان تەنها دوای نوێکردنەوەی data.js لە GitHub دیار دەبن.
- localStorage تەنها لە هەمان براوزەر/ئامێرە. بۆ گواستنەوە بۆ کۆمپیوتەرێکی تر، data.js ـی نوێ هەناردە بکە و لە ئەدمینی ئەو ئامێرەدا بارکردنی بکە.
- چونکە ئەدمین بێ Login ـە، پەڕەی admin.html لە ماڵپەڕی گشتی بڵاو مەکەرەوە.

هەڵەی باو:
- ئەگەر نەخشە نەهات، ئینتەرنێت بپشکنە و جارێکی تر پەڕەکە بکەرەوە.
- بۆ دوگمەی «شوێنی من»، مۆڵەتی شوێن لە وێبگەڕ بدە؛ بەڵام کلیککردن لەسەر نەخشە بەبێ ئەو مۆڵەتەش کار دەکات.
- زانیاری ناونیشان و ژمارەی تەلەفۆن تەنها بە ڕەزامەندی خاوەن خزمەتگوزاری بڵاو بکەرەوە.


داتای دەستپێکی نزیکەی ٣٩ شوێن و چێشتخانە لە public/data.js دانراوە؛ پەڕەی ئەدمین ئەو داتایە بە خۆکار دەخوێنێتەوە.


بارکردنی وەشانی نوێی ماڵپەڕ بۆ GitHub:
- ناوەڕۆکی فۆڵدەری github-pages هەمووی بار بکە بۆ ڕەگی repository ـەکەت؛ واتە index.html، data.js، manifest.webmanifest، sw.js و icons دەبێت لە هەمان ئاستدا بن.
- فۆڵدەری private-admin بۆ GitHub Pages بار مەکە؛ تەنها لە کۆمپیوتەرەکەت بهێڵەوە.
- ئەگەر تەنها شوێنێکی نوێت زیاد کردووە، دەتوانیت تەنها github-pages/data.js نوێ بکەیتەوە و لە GitHubدا جێگای data.js ـی پێشوو بگرێتەوە.
